# Native AMD64 qualification

This job does not deploy, activate V2, modify decoder code, or change any frozen hash. It is separate from web E2E and Cloudflare Builds access. Production remains on its verified release until an explicitly reviewed native release.

`tests/fixtures/canonical-v2-arm64-reference.json` is a lossless selection of the 17 retained fixture receipts from the 2026-09-13 ARM64 evidence `wNPGQR`, not output generated by the new candidate. The source report SHA-256 and unchanged implementation hashes are included. Both historical targets and both repeats were verified identical before copying the receipts. Existing manifests/references remain unmodified.

The new target runner:

- Verifies implementation, contract, dependency/profile and source hashes before execution.
- Generates exactly the existing four error cases/eight EXIF variants and verifies their retained input hashes.
- Compares prepared JPEG, RGB, color, resize, orientation, geometry, profile/source provenance and canonical/tensor hashes with zero tolerance.
- Runs ten fresh-process repeats at concurrency 1/2/4 with reversed admission order on alternate repeats: 510 cases and 1950 positive stage comparisons per build.
- Stops admission on a mismatch, retains diagnostics, and fails the job. No golden-update option exists.
- Hashes every input before/after; only hash receipts, not photos, are uploaded as private CI artifacts.
- Does not claim cold filesystem cache, production throughput, sports-model quality or customer authority.

The manual/qualification-branch GitHub workflow uses a native Linux X64 runner, pinned action SHAs, read-only repository permissions, no repository secrets, and the existing checksum-pinned library bootstrap. Normal and ASan/UBSan variants rebuild all three libraries separately. The only downloaded photographs are the two already approved public CC0 fixtures documented in `native/README.md`; no customer corpus is discovered or uploaded.

Local harness check, not AMD64 qualification:

```sh
bun test tests/canonical-v2-target-parity.test.ts tests/canonical-v2-isolation.test.ts
node tests/canonical-v2-target-parity.mjs --raw-root /path/to/approved/raw-fixtures --probe native/build-v2/v2-probe --report /tmp/v2-local-parity.json
```

AMD64 mode additionally requires Linux x64 and GitHub's native X64 runner metadata. Emulation cannot substitute for target qualification. CI provenance, compiler versions and reports must be reviewed before claiming a pass. No result has been assumed in this document.

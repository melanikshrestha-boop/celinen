# Source Serif 4

Celinen uses the same interface family as Wonder, served from its own origin so
rendering does not depend on a third-party font service. Large financial values
and graph axes use the separate system-monospaced token; this family is for
interface labels, navigation, headings, form controls and prose.

These are unmodified variable WOFF2 font bytes from Adobe's official
[source-serif repository](https://github.com/adobe-fonts/source-serif), pinned to
release-branch commit `5f220b17d27ed64873f22cde0dd593685387bd19`:

- [Roman original](https://github.com/adobe-fonts/source-serif/blob/5f220b17d27ed64873f22cde0dd593685387bd19/WOFF2/VAR/SourceSerif4Variable-Roman.ttf.woff2)
- [Italic original](https://github.com/adobe-fonts/source-serif/blob/5f220b17d27ed64873f22cde0dd593685387bd19/WOFF2/VAR/SourceSerif4Variable-Italic.ttf.woff2)
- [Original license](https://github.com/adobe-fonts/source-serif/blob/5f220b17d27ed64873f22cde0dd593685387bd19/LICENSE.md), included unchanged as `OFL.md`

Only the filenames omit `.ttf`; the font contents have not been converted,
subsetted or renamed internally. Both faces support weights 200–900 and optical
sizing. The CSS family label matches Wonder's `Source Serif 4`.
